# 이미지 출처

- `notices-demo.png`와 `keywords-demo.png`는 Spring Boot 애플리케이션을 임시 H2 데이터베이스로 실행해 촬영했습니다. 계정·학과·공지는 예제 데이터이며 실제 메일과 Kafka 연동은 비활성화했습니다.
- `architecture.svg`와 `architecture.png`는 이 저장소의 처리 흐름을 설명하기 위해 직접 작성한 구성도입니다.
- `brands/`의 기술 로고와 구성도에 포함된 로고는 [Simple Icons 13.16.0](https://github.com/simple-icons/simple-icons/tree/13.16.0)의 SVG를 사용했습니다. 아이콘 묶음은 [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/13.16.0/LICENSE.md)으로 제공됩니다. 브랜드의 상표 권리는 각 권리자에게 있으며 사용 기술을 식별하기 위한 목적으로 표시했습니다.

화면에는 실제 계정, 방문 기록, 개인정보를 사용하지 않았습니다. 기존 앱의 로고와 저작권 표시는 유지했습니다.
